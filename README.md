# 櫃內選物：保險櫃選購指南

為內部淨空寬 60 × 深 45 × 高 45 cm 的系統櫃整理的繁體中文選購指南。

網站：https://river-ye.github.io/safe-buying-guide/

## 執行與測試

不需要安裝套件或建置。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
# 開啟 http://127.0.0.1:8765/

node --test --experimental-test-coverage eligibility.test.mjs
```

## 資料與規則

`products.json` 是唯一商品資料來源，含價格、購買網址、精確型號、尺寸、逐項證據、評價查核範圍與限制。所有價格與庫存是查核日快照，不自動更新。

正式推薦必須確認：含突出物與原廠必要餘量可放入、鑰匙／可自訂密碼／指紋各自獨立開門、一片以上層板、全鋼實心鎖栓、型號本身沒有 Wi-Fi，以及台灣購買與保固。防火認證及固定功能不列必備。

`eligibility.mjs` 的 `assess(product)` 回傳狀態與逐項判斷：

- `recommended`：硬性條件與空間資料皆有對應來源，且完成同型號負評搜尋。
- `pending`：缺證據，不列正式推薦；在候選區揭露缺口。
- `excluded`：不符合硬性條件或有可查證同型號產品負評；不顯示，也不應收進發布的商品資料。

尺寸需有含全部突出物的確認與來源。`requiredSpace` 需包含寬、深、高及對應來源 `source`，不能小於實際外廓。沒有提到 Wi-Fi 不等於無 Wi-Fi，未知值一律為 `null`，不能以 `true` 代替待確認。

## 更新與發布

1. 核對精確型號／版本、原廠手冊與購買通路，更新證據、查核日、價格、庫存及運送資訊。
2. 搜尋同型號別名、購物評論、Mobile01、PTT、Dcard，記錄可讀範圍；發現可查證產品負評即從商品資料移除。
3. 跑測試並以桌面／手機檢查載入、比較表、候選展開、尺寸對照與外部購買連結。
4. 推送 `main`。GitHub Pages 從 `main` 根目錄發布，`.nojekyll` 保留原生靜態檔案。

沒有後端、追蹤碼、遠端字型或第三方前端依賴；來源與購買連結由使用者點選後開啟，不會送出表單或購買。
